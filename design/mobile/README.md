# Mobile app designs

Design exports for the Home Record Keeper mobile app. These are reference only:
they are kept in git but are **not deployed** to Vercel (see `.vercelignore`).

Source of truth: Figma file "Home Service Webapp", page **📱 Mobile**
https://www.figma.com/design/JbHYIuzPOyY9TDpBCumDHK/Home-Service-Webapp

| File | Section | Screens |
|---|---|---|
| `00-home.png` | Home | Full-length home: property card, home systems, quick links (Documents), Request Service, tab bar |
| `01-spaces.png` | Space | Spaces list, Space detail (Items / Sub-spaces), Sub-space detail, scrolled sticky-header states |
| `02-documents.png` | Documents | Item / Property tabs, folders (grid + list), new / rename / delete folder, document menu, delete document, empty folder, and the Upload documents flow (item and property paths) |
